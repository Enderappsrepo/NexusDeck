NexusDeck on Steam Deck

Install

Recommended: graphical installer in Desktop Mode (Konsole):

curl -fsSL https://enderappsrepo.github.io/NexusDeck/i.sh -o install.sh && bash install.sh --gui

Or one-line terminal install:

curl -fsSL https://enderappsrepo.github.io/NexusDeck/i.sh | bash

Direct release link (alternative):

curl -fsSL https://github.com/Enderappsrepo/NexusDeck/releases/latest/download/i.sh | bash

Uninstall

curl -fsSL https://enderappsrepo.github.io/NexusDeck/u.sh | bash

Direct release link (alternative):

curl -fsSL https://github.com/Enderappsrepo/NexusDeck/releases/latest/download/u.sh | bash

Enable GitHub Pages (Settings → Pages → Deploy from branch main, folder /docs) if these URLs 404.
