Install NexusDeck

Steam Deck and Linux use Flatpak. The graphical installer is the easiest path — or paste a one-liner in Konsole (Desktop Mode).

Windows

Download the NSIS installer or portable build from GitHub Releases. Build locally with npm run tauri build if you are developing.

After install

  1. Sign in with your Nexus API key Settings → Nexus — required for browsing and downloads.
  2. Add your game Run the setup wizard for Skyrim SE or Fallout 4 (paths, staging, script extender).
  3. Turn on Receive (optional) Settings → Remote — pair the companion app or send mods from another PC.
  4. Launch from Gaming Mode If you added the Steam shortcut, restart Steam once after install.

Help & uninstall

How do I update NexusDeck?

Re-run the install script, or use the in-app updater when a new release is available. Flatpak installs can also use flatpak update com.nexusdeck.app.

GitHub Pages shows 404 — what now?

Enable Pages: repo Settings → Pages → deploy from branch main, folder /docs. Or use the direct GitHub Releases install command above.
